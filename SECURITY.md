# Security Policy / 安全策略

## Supported Version

| Version | Supported |
|---|---|
| 1.0.x | ✅ |

## Reporting a Vulnerability / 报告安全问题

如果你发现 UploadSentinel 本身存在安全漏洞，请优先通过 GitHub Security Advisory / Private Vulnerability Reporting 联系维护者。

If you discover a vulnerability in UploadSentinel itself, please preferably use GitHub Security Advisories / Private Vulnerability Reporting to contact the maintainer.

请包含：

- 受影响版本
- 问题描述
- 复现步骤
- 潜在影响
- 建议修复方式（如果有）

Please include:

- affected version
- description
- reproduction steps
- potential impact
- suggested fix, if available

在修复发布前，请避免公开完整利用链。

Please avoid publishing a complete exploit chain before a fix is available.
